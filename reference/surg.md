# Intestinal surgery data involving 844 cancer patients. The data consists of pairs (\\n_i\\, \\s_i\\) where \\n_i\\ is the number of satellites removed and \\s_i\\ is the number of satellites found to be malignant.

Intestinal surgery data involving 844 cancer patients. The data consists
of pairs (\\n_i\\, \\s_i\\) where \\n_i\\ is the number of satellites
removed and \\s_i\\ is the number of satellites found to be malignant.

## Usage

``` r
data(surg)
```

## References

Gholami, et. al. Number of Lymph Nodes Removed and Survival after
Gastric Cancer Resection: An Analysis from the US Gastric Cancer
Collaborative. J Am Coll Surg. 2015 Aug;221(2):291-9. doi:
10.1016/j.jamcollsurg.2015.04.024.
