# Package index

## All functions

- [`bardWordCount`](https://bnaras.github.io/deconvolveR/reference/bardWordCount.md)
  : Shakespeare word counts in the entire canon: 14,376 distinct words
  appeared exactly once, 4343 words appeared twice etc.
- [`deconv()`](https://bnaras.github.io/deconvolveR/reference/deconv.md)
  : A function to compute Empirical Bayes estimates using deconvolution
- [`deconvolveR`](https://bnaras.github.io/deconvolveR/reference/deconvolveR-package.md)
  [`deconvolveR-package`](https://bnaras.github.io/deconvolveR/reference/deconvolveR-package.md)
  : R package for Empirical Bayes \\g\\-modeling using exponential
  families.
- [`disjointTheta`](https://bnaras.github.io/deconvolveR/reference/disjointTheta.md)
  : A set of \\\Theta\\ values that have a bimodal distribution for
  testing
- [`surg`](https://bnaras.github.io/deconvolveR/reference/surg.md) :
  Intestinal surgery data involving 844 cancer patients. The data
  consists of pairs (\\n_i\\, \\s_i\\) where \\n_i\\ is the number of
  satellites removed and \\s_i\\ is the number of satellites found to be
  malignant.
